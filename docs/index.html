06 · Industrial data engineering · Team project

Production Data Collection & Analysis

Demonstration project · OPC UA / MQTT · Airflow · Superset

A team project for collecting and analyzing industrial data. Node-RED flows acquire OPC UA data into MySQL and display MQTT telemetry. Python notebooks parse JSON sources into PostgreSQL; hourly Airflow DAGs use pandas to clean, normalize and consolidate records for analysis in the customer's Apache Superset environment.

OPC UA acquisition
OPC UA→Node-RED→MySQL→Superset
Live telemetry
MQTT→Node-RED→Live dashboard
JSON processing and analytics
JSON · ids3 / ids5→Python / Jupyter→PostgreSQL · raw→Airflow / pandas→PostgreSQL · processed→Superset
The repository contains the team project artifacts: Node-RED flows, JSON parsing notebooks, Airflow DAGs and dashboard exports. This is a demonstration implementation. Integration into the customer's infrastructure accounts for data sources, security requirements and operational constraints.

07 · Event-driven integration · API-first

Event Hub · Universal Event Bus

Implemented event core · Illustrative integration architecture

An independently developed event bus core on FastAPI and PostgreSQL. A canonical event API, persistent event history, routing and delivery workers decouple data producers from business services. The implementation includes idempotency, leases, retries and service-scoped publishing permissions. The architecture can be adapted to different domains by configuring connectors, event contracts and processing rules to meet customer requirements.

The diagram illustrates one possible integration of Event Hub with equipment, business services and AI applications. Dashed elements represent components selected and implemented for a specific project: protocol adapters, an edge gateway and an MCP interface. MCP exposes the core's data and functions to AI applications through APIs. Integrations, event and incident processing, and data-quality rules are defined by customer requirements. The repository contains the implemented event core.

08 · Applied AI · Retrieval-Augmented Generation

Evidentum · RAG Assistant

Hackathon project · 3rd place · Hybrid RAG

A RAG (Retrieval-Augmented Generation) research prototype for searching, comparing and synthesizing Russian and international clinical guidelines. PDF/HTML ingestion and chunking feed PostgreSQL with pgvector and full-text indexes. Hybrid retrieval and reranking supply source passages to an LLM, which generates an answer with references.

The RAG architecture can be adapted to the customer's requirements and infrastructure across domains. Applying it beyond clinical guidance involves configuring the document corpus, domain model, access controls and answer-quality evaluation criteria.

Knowledge ingestion
PDF / HTML→Chunks + embeddings→PostgreSQL / pgvector
Retrieval-Augmented Generation
Question→Vector + full-text retrieval→Reranking→LLM + source references
Built as a team hackathon project and subsequently extended as an engineering portfolio artifact. Source references support traceability but do not establish medical validity; Evidentum is not a clinically validated decision-support system.

Production-informed engineering

This platform is not a cloned employer system. It is an independently built laboratory that demonstrates design patterns learned through real data-platform engineering.

Engineering pattern

Separate orchestration from compute

Airflow manages task state and scheduling. Spark provides independent distributed data processing.

Engineering pattern

Reuse shared platform services

Identity, network routing and object storage are provided as shared infrastructure rather than copied per application.

Engineering pattern

Document limits and failure modes

Single-host resource budgets, setup dependencies and smoke tests are documented explicitly.

All public material uses independent configurations and demonstration-oriented descriptions. No employer source code, production datasets, credentials, internal endpoints or undisclosed architecture details are published.
